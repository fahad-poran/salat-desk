    Jamaat alerts

    Before each Jamaat the screen shows a red, blinking warning with the time left. Choose how many minutes before the Jamaat it starts (at most the time between the Waqt start and the Jamaat) and whether the phone also shows a notification, with the notification light where the phone has one.

    Prayer Notify Minutes before Jamaat

    Notifications are created on this phone only. The notification light usually blinks while the screen is off.

    When blinking is off, the warning stays red but does not blink. A reduced-motion system setting always turns blinking off. These preferences are stored only on this device.

    Display & ambient mode

    Between prayers the dashboard switches to a dim clock that moves every minute, which protects the screen from burn-in. The full dashboard returns before each Jamaat, and for two minutes after you tap the screen. These preferences apply immediately and are stored only on this device.

    Loading content status…

    About 70 new Ayat and 200 new Hadith are downloaded once a week. Use the Quran and Hadith buttons on the dashboard to read everything and to remove anything you don't want shown.

    Quran Arabic: Tanzil.net (Uthmani). Quran English: Sahih International. Both via AlQuran.cloud. Hadith Arabic and English: fawazahmed0/hadith-api, from Sahih al-Bukhari, Sahih Muslim, An-Nawawi's Forty Hadith and Forty Hadith Qudsi. Everything downloaded is stored on this device and works offline.

    Brightness applies only while this app is open; the phone's own brightness setting is not changed.
